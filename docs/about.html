About PlaceMellon

PlaceMellon fills Carnegie Mellon mockups, prototypes, and unfinished pages with real CMU photos at whatever size the layout needs.

Where the Photos Come From

The photos come from CMU Selects, University Communications & Marketing's collection of campus photography. CMU Selects says they're for "use by the Carnegie Mellon University community in university-related communications and marketing," so use PlaceMellon for CMU work. For a finished page, choose and credit a photo there.

The Scotty in ?scotty and ?profile is traced from Ask Scotty's avatar.

Which Photo Is This?

Each photo's response has an X-Photo header with its file name, so you can find it in CMU Selects.

How It Works

PlaceMellon keeps a list of the CMU Selects photos and refreshes it every few hours. When you ask for a size, it fetches that photo's preview from CMU Selects, crops it, and sends it to you. It doesn't keep copies of the photos.

PlaceMellon first narrows the list to photos shaped like your size: landscape for wide sizes, portrait for tall ones, and any photo for sizes close to square. It then picks one by rendezvous hashing, scoring each photo by your size and its ID and taking the highest. So the same size always gets the same photo, and when University Communications & Marketing adds or removes photos, nearly every size keeps the photo it had. With ?random, it skips the scoring and picks any photo of the right shape.

To crop, it fetches the smallest preview that covers your size and keeps the most interesting part of the photo, where there's the most detail and color, rather than simply the middle. Scotty is drawn from vector shapes, so it stays sharp at any size. It holds recently made images in memory for a short while (nothing is saved to disk), and browsers may keep each one for a day, so repeat requests are fast. Random photos are never held.

PlaceMellon is a small TypeScript app built with Express and sharp, and its code is public. The GitHub repository has the code, its tests, and documentation. To report a problem or suggest a change, open an issue or send a pull request.
