Customize Your Placeholder

By default, each size always gets the same photo. Options let you choose a category, get a random photo instead, switch to black and white, or use Scotty, standing or as a round profile picture.

OptionWhat It DoesExample
?category= Only photos from one category: campus, classrooms, labs, or life.
?random A different photo every time. A page shows one image per address, so number them for several on one page: ?random=1, ?random=2.
?gray Grayscale. ?grayscale works too, and so does /g/ in front, as on placekitten: /g/400/300.
?scotty Scotty instead of a photo, standing on the bottom edge.
?profile Scotty as a round profile picture, for people who don't have a photo yet. Always square: /96?profile.

Add options after a ?, joined with &, in any order: /400/300?category=labs&gray. Category and random options apply only to photos. Leave them out when using Scotty or a profile picture. If an option is misspelled or isn't supported, an error message will list the available options.
